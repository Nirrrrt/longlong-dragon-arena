# Longlong Dragon Arena
A free pixel arena survival game starring Longlong, a baby green dragon.
## Play
Open index.html in a browser. Move with WASD or the on-screen joystick, breathe fire with mouse or Space, bite with K, and dash with Shift. Survive waves of slimes, bats, spore-shrooms and brutes, hide in the grass to break tracking, and grab gems and hearts. Eat a fuel poop to keep firing flames — but every poop has a 50% chance to cost 40 HP. Playable in English, Japanese, Korean, Russian, and Chinese.
## Develop
The game is a single HTML file (index.html). The original sprite sheet is in assets/sprite-sheet.jpg. Note: the sprite sheet artwork was AI-generated with Gemini.
